# ADR-002 · 引用校验作为硬门槛

- **状态**：已采纳
- **日期**：2026-10-22
- **相关**：计划书 §5.4、§3.3 约束 R3、§8.3 检查 C-3

## 背景

LLM 生成的每条结论都带一段「证据原文」。问题是：**模型可能引用并不存在的内容**。
一段看起来合理的「主导 Kubernetes 集群迁移」如果原文中根本没有，
面试官拿着去追问会非常尴尬 —— 而且这属于事实性错误，不是文风问题。

常见做法是在 prompt 里写「必须引用原文，不得编造」。这属于**相信模型**。
prompt 是软约束，模型在长上下文、任务压力大、或被诱导时都会违反。

## 备选方案

| 方案 | 做法 | 问题 |
|---|---|---|
| A. 只在 prompt 里约束 | 「必须引用原文」 | 违反时无从发现，幻觉直接进入报告 |
| B. 引用后人工复核 | 面试官自己看 | 把校验成本转嫁给用户，且报告本身已经不可信 |
| C. **代码校验引用** | 引用必须能在输入文本中定位，否则丢弃结论 | 需要实现归一化匹配，但判定明确 |

## 决策

采用 **C**：引用校验是**硬门槛**。

实现要点（`agents/interview-agent/app/hr/compliance.py`）：

```python
def verify_evidence_ref(ref: str, source_text: str, min_length: int = 8) -> bool:
    """
    去掉空白与标点后做子串匹配（容忍 LLM 微调标点）。
    不通过 → 该条结论整体丢弃。
    """
```

- **归一化后子串匹配**：容忍标点与空白差异，但不容忍改写内容。
- **最短长度 8**：太短的引用容易「碰巧命中」，失去校验意义。
- **不通过就丢弃整条结论**，而不是「保留结论但不显示引用」——
  一条无法溯源的结论没有价值。

同时把校验失败次数记进 `t_agent_invocation.evidence_failed`，
**幻觉率因此是一个可观测指标，而不是只能靠感觉**。

## 代价

- 模型会「被拒」：引用写得不精确时整条结论丢失。
  实际效果是模型学会更精确地摘抄原文 —— 这是期望的行为。
- 归一化规则需要维护。中文标点、英文标点、引号变体都要覆盖。
- 阈值 8 是经验值，长文本引用天然更长，短文本引用可能误杀。

## 什么条件下推翻它

如果业务场景需要保留「无法溯源但可能有用」的结论，
可以把「丢弃」改成「降级展示 + 标记未验证」。
但**涉及合规判断的结论**（学历、年限等硬门槛）不能降级 ——
那部分必须溯源。
